BrowserLens

2026.03 - 2026.09

Overview

Interactive diagnosis workspace for browser-agent trajectories. A recorded run is reconstructed as a URL → Viewport → State-Anchored Action graph stack, so reviewers can spot repeated states and navigation loops, then check each cue against replayable evidence. Submitted to UIST 2026 Posters (joint work with Mingyu Kim and Seongkook Heo, UNIST).

Technologies

Python Playwright Web Agents Interactive Visualization DOM & ARIA Snapshots

Features

  • Layered State-Action Graph - Groups visits by normalized URL, viewport geometry, and state-anchored actions; identical identities collapse into one node.
  • Cue-Driven Review - Visit counts, cycle edges, no-op markers (unchanged DOM/ARIA + ≤1% screenshot diff), and hidden-cue badges point at where to look.
  • Evidence-Linked Inspection - Selecting a node retrieves screenshots, DOM/ARIA snapshots, tool logs, and model context instead of replacing them.
  • Walkthrough - On a 98-tool-call YC directory run ending in exceeded max steps, surfaced a 35-visit company page and a no-op "All batches" click.
