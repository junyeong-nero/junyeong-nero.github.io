Delivery

2022.02 - 2022.03

Overview

A service for delivery drivers to store and share apartment entrance passwords, aiming to reduce delays caused by missing access information. Originally built as Android Native (Java), then ported to Flutter, and now rewritten as a lightweight mobile-first HTML/JS web demo.

Technologies

Android Native Java Flutter HTML/JS Firebase

Features

  • Password Storage - Securely store apartment entrance codes
  • Community Sharing - Share access information with other drivers
  • Quick Lookup - Fast search by address
  • Offline Support - Works without internet connection
