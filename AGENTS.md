# Git Commit Rules

## Author Identity

All commits must be authored as:

```
Name:  junyeong-nero
Email: junyeong.nero@gmail.com
```

Before running any `git commit`, ensure the local repo config is set:

```bash
git config user.name "junyeong-nero"
git config user.email "junyeong.nero@gmail.com"
```

Do not commit under any other name or email.
